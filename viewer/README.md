# 左右代码对照

在仓库根目录双击 `查看模板对照.bat`，自动读取 `src/` 与 `src-acm/` 并在默认浏览器中打开页面。也可以从任意工作目录运行：

```powershell
python tools/build_compare_view.py --open
```

仅生成数据而不打开浏览器：

```powershell
python tools/build_compare_view.py
```

生成后可以直接打开 `viewer/index.html`。这是离线页面，不需要 Node.js、网络连接或常驻服务器。`templates.js` 是本地生成的源码快照，不提交 Git；新检出仓库需先运行一次生成命令。修改模板后重新运行启动入口，刷新原页面即可看到新快照。

- 左侧目录按分类浏览，可搜索中文名或路径，按 `/` 聚焦搜索，`Esc` 清空筛选。
- 左边显示完整封装版，右边显示赛时手抄版。默认差异对齐，插入的空白行没有行号。
- “原始代码”保持各自源码的行顺序与行数；“同步滚动”可以单独开关。
- 用上下箭头或 `Alt+↑`、`Alt+↓` 循环跳转差异。
- 两边的“复制”分别复制原始文件，保留代码和说明注释，不包含行号、差异标记或对齐空行。
- 拖动中间分隔条调节宽度；双击恢复各半。分隔条聚焦时可用左右方向键，`Home` 恢复各半。
- 支持字体大小、深浅配色，记住上次打开的文件和视图设置。窄屏仍保留左右对照，代码可以横向滚动。

有效代码行统计只排除空行和以 `//` 开头的行，用于比较抄写量，不是 C++ 语法统计。

生成器测试：

```powershell
python -m unittest discover -s tests -p test_compare_view.py
```
